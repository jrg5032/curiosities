Google Chat Indent Extension – Test Harness

How to test:
1. Click inside a composer box below and create a bullet list (type - then space, or click below where a list is pre-populated)
2. Press Tab on a bullet item → should convert to indented unicode sub-bullet
3. Press Tab again → should increase indent level
4. Press Shift+Tab → should decrease indent level
5. At level 0 unicode bullet, Shift+Tab → should convert back to native bullet
6. Press Shift+Enter on a sub-bullet → new line at same indent level
7. Press Shift+Enter on an empty sub-bullet → exits sub-bullet mode
8. Copy a nested bullet list from Google Docs or OneNote and paste into a composer → nesting should be preserved

What to verify: Sub-bullets should appear visually indented relative to the parent bullet, not flush-left.
